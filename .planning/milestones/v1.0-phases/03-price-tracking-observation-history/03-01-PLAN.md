# Plan 03-01: Price Tracking & Observation History

## Goal
Implement and verify historical price tracking for catalog products, ensuring snapshot deduplication, multi-currency calculation safety, baseline peak handling, and on-demand polling endpoints.

## Tasks
1. **Model**: Verify `PriceSnapshot` schema with `product_id`, `price`, `original_price`, `currency`, `source`, `observed_at`.
2. **Service**: Implement `record_price_snapshot`, `get_price_history`, and `poll_product_price` with deduplication and multi-currency guards in `app.services.harvester.price_history`.
3. **Endpoints**: Expose `GET /api/v1/harvester/products/{product_id}/price-history` and `POST /api/v1/harvester/products/{product_id}/check-price` in `app.api.v1.harvester`.
4. **Verification**: Run comprehensive test suite in `backend/tests/test_milestone7_price_tracking.py` verifying all requirements.
